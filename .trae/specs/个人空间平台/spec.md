# 个人空间平台 - 产品需求文档 (PRD)

## 概述
- **摘要**: 个人空间平台是一个支持访客公开展示与用户私有管理的个人作品集平台。访客可通过 `/u/{username}` 浏览用户公开主页（纵向单页滚动风格），用户登录后可在后台管理个人资料、任务计划、动态、项目、外观和账号。
- **目的**: 为个人（特别是学生群体）提供一个集中展示学业成就、项目作品、思想动态的在线作品集空间，同时支持任务管理与 AI 辅助写作。
- **目标用户**: 学生用户、需要个人作品集的创作者、求职展示者。

## 目标
- 构建完整的访客公开展示页面，以纵向平铺滚动方式呈现用户的 Hero 名片、个人概况、任务计划、项目作品、动态五大板块
- 实现功能完备的后台管理系统，支持个人资料、任务、动态、项目、外观、账号六大模块
- 提供 AI 智能拆解任务和 AI 文稿生成两大辅助功能
- 支持主题配色切换、明暗模式、板块拖拽排序与显示隐藏控制
- 确保权限隔离：私有内容不对外暴露，任务子任务永不公开

## 非目标 (超出范围)
- 不开发留言/评论板块
- 不实现无限层级的任务嵌套（硬性限制三级）
- 不开发社交关系链（关注/粉丝功能）
- 不实现独立的字数统计输入框（由用户在提示词中自行指定）
- 不开发多用户协作功能
- 不提供独立的 iframe 预览路由（已废弃 `/dashboard` 路由，改为新开标签页预览）

## 背景与上下文
- 项目为全新搭建，当前工作目录为空
- 公开主页风格参考 Calvino 纵向单页个人作品集模板
- 页面布局采用纵向平铺滚动，无侧边导航栏，仅顶部横向导航菜单
- 技术栈待定，建议使用主流全栈框架（React/Vue + Node.js/Java 等）

## 功能需求

### 访客端页面
- **FR-1**: 访客可访问 `/u/{username}` 查看用户公开主页，页面以纵向平铺滚动方式展示
- **FR-2**: 公开主页包含顶部导航栏（站点名称 + 首页/全部动态/项目作品/关于我 + 明暗切换 + 主题配色切换）
- **FR-3**: Hero 首屏区：展示圆形头像、昵称、身份标签、个人 Slogan、自我介绍、社交链接、浏览动态/查看项目按钮
- **FR-4**: 个人概况板块：教育经历、学生工作、荣誉奖项、技能标签，两栏网格布局，支持隐藏
- **FR-5**: 任务计划清单板块：PC 横向滚动卡片/移动端纵向排列，显示任务标题、截止日期、分类标签、进度条、紧急等级配色
- **FR-6**: 公开任务卡片点击弹出提示弹窗，文字为"完整任务拆解、子任务详情仅主人登录后可见"
- **FR-7**: 项目作品板块：网格卡片布局，显示项目配图、名称、简介、技术栈、完成时间，支持公开/隐藏
- **FR-8**: 动态板块：PC 横向滚动/移动端纵向，显示日期、标题、摘要、标签，底部查看全部动态按钮
- **FR-9**: 页脚显示用户自定义签名与版权文字
- **FR-10**: 全部动态汇总页 `/u/{username}/dynamic`：标签筛选、分页加载、Markdown 渲染
- **FR-11**: 单条动态详情页 `/u/{username}/dynamic/{id}`：完整渲染 Markdown、图片、代码块

### 后台管理页面
- **FR-12**: 顶部导航包含：查看公开主页（新开标签）、个人资料设置、任务管理、动态管理、项目管理、外观设置、账号设置
- **FR-13**: 个人资料设置 `/dashboard/profile`：头像、昵称、Slogan、自我介绍、社交链接、教育经历、学生工作、荣誉奖项、技能标签的增删改
- **FR-14**: 板块排序管理：可视化拖拽排序，每个板块可开关显示/隐藏，支持一键恢复默认排序
- **FR-15**: AI 文稿生成模块：快捷需求标签、自定义需求输入框、读取已有资料并 AI 生成、富文本编辑器、复制文本
- **FR-16**: 任务管理 `/dashboard/task`：新建主任务、AI 智能拆解目标、任务卡片列表、编辑/删除/公开设置、三级子任务结构
- **FR-17**: 任务详情弹窗：编辑基础信息、新增一二级子任务、子任务勾选完成/新增/删除/排序
- **FR-18**: 动态管理 `/dashboard/dynamic`：撰写新动态、列表展示、Markdown 编辑器、图片上传、代码块、公开/私密设置
- **FR-19**: 项目管理 `/dashboard/project`：新增项目、列表展示、编辑弹窗（名称、简介、技术栈、成果、外部链接、完成时间、配图、公开/隐藏）
- **FR-20**: 外观设置 `/dashboard/style`：主题配色选择、浅色/暗色模式、模板选择
- **FR-21**: 账号设置 `/dashboard/account`：修改密码、基础信息、注销账号提示

### AI 功能
- **FR-22**: AI 智能拆解目标：输入目标后自动生成主任务→一级子任务→二级子任务三级结构，预览并一键导入
- **FR-23**: AI 文稿生成：读取用户已填写的教育/学生工作/奖项/项目信息，结合自定义指令生成文稿

### 权限与安全
- **FR-24**: 访客访问私有动态/私有任务 URL 时被后端拦截
- **FR-25**: 所有任务子任务、任务备注在公开页面永不渲染
- **FR-26**: 任务层级硬性上限三级，禁止无限嵌套

## 非功能需求
- **NFR-1**: 响应式设计：PC 多栏布局，移动端自动转为单列堆叠
- **NFR-2**: 交互动效：圆角卡片，hover 上浮动画
- **NFR-3**: 主题支持：至少支持浅色/暗色模式切换，支持主题色块自定义
- **NFR-4**: 视觉风格：公开主页参考 Calvino 纵向单页作品集风格，独立板块充足留白
- **NFR-5**: 性能要求：页面首屏加载时间 < 3秒（理想条件下）
- **NFR-6**: 安全性：访客无法绕过权限访问私有内容，后端做路由拦截
- **NFR-7**: 可扩展性：模板系统预留扩展能力，后续可增加更多主题模板

## 约束
- **技术**: 全栈框架选型自由（建议 React + Node.js + PostgreSQL 或 Vue + Spring Boot + MySQL）
- **业务**: 任务层级最多三级；无独立字数输入框（由用户在提示词中指定）
- **依赖**: AI 功能依赖第三方 AI API；图片存储依赖对象存储服务
- **前端**: 所有页面采用纵向平铺滚动布局，无侧边导航栏
- **后端**: 需要实现基于角色的访问控制（RBAC），区分访客与用户

## 假设
- 用户已拥有或可注册账号
- 用户熟悉 Markdown 语法（用于动态编辑）
- AI 服务可用且响应时间在可接受范围内（<10秒）
- 用户具备基本的网络环境，能上传图片等媒体资源
- 单用户板块数据量在可管理范围内（不会出现数百个板块导致拖拽性能问题）

## 验收标准

### AC-1: 公开主页完整呈现
- **Given**: 用户已登录并完成基础资料填写，所有板块均设为公开显示
- **When**: 访客访问 `/u/{username}`
- **Then**: 页面以纵向滚动方式依次展示顶部导航、Hero 名片、个人概况、任务计划清单、项目作品、动态、页脚所有板块
- **验证**: `human-judgment`
- **备注**: 视觉风格需符合 Calvino 纵向单页作品集参考风格

### AC-2: 权限隔离正确
- **Given**: 用户有私有动态和私有任务
- **When**: 访客直接访问私有内容的 URL 或查看公开主页
- **Then**: 私有内容被后端拦截，公开页面不渲染任何子任务和任务备注
- **验证**: `programmatic`

### AC-3: 任务三级层级限制
- **Given**: 用户在后台编辑任务
- **When**: 尝试新增第四级子任务
- **Then**: 系统禁止操作并给出提示
- **验证**: `programmatic`

### AC-4: AI 智能拆解功能可用
- **Given**: 用户在任务管理页面
- **When**: 点击"AI 智能拆解目标"并输入目标后点击开始拆解
- **Then**: 系统生成三级任务结构并支持预览和一键导入
- **验证**: `programmatic`

### AC-5: AI 文稿生成功能可用
- **Given**: 用户已填写教育、工作、奖项、项目等资料
- **When**: 在个人资料设置页点击"读取已有资料并 AI 生成"
- **Then**: 系统结合用户资料和自定义需求生成文稿
- **验证**: `programmatic`

### AC-6: 板块拖拽排序与显示控制
- **Given**: 用户在个人资料设置页
- **When**: 拖拽调整板块顺序或切换显示/隐藏开关
- **Then**: 排序和显示设置保存成功，访客刷新公开主页后看到更新后的效果
- **验证**: `programmatic`

### AC-7: 主题与模式切换
- **Given**: 用户在外观设置或访客在公开主页
- **When**: 切换主题配色或明暗模式
- **Then**: 页面主题实时更新，设置被持久化
- **验证**: `human-judgment`

### AC-8: 响应式布局
- **Given**: 用户在 PC 端和移动端访问
- **When**: 访问公开主页
- **Then**: PC 显示多栏网格布局，移动端自动转为单列堆叠
- **验证**: `human-judgment`

### AC-9: 动态 Markdown 渲染
- **Given**: 用户撰写包含 Markdown 格式（含代码块、图片）的动态
- **When**: 访客查看该动态详情页
- **Then**: Markdown 正确渲染，代码块高亮，图片正常显示
- **验证**: `human-judgment`

### AC-10: 后台导航"查看公开主页"
- **Given**: 用户已登录后台
- **When**: 点击顶部"查看公开主页"
- **Then**: 新标签页打开 `/u/{username}`，以访客视角预览
- **验证**: `programmatic`

### AC-11: 公开任务卡片点击弹窗
- **Given**: 访客在公开主页看到公开任务卡片
- **When**: 点击任务卡片
- **Then**: 弹出提示弹窗，显示"完整任务拆解、子任务详情仅主人登录后可见"
- **验证**: `programmatic`
